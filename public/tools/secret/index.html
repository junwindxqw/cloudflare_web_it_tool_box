管理令牌只保存在你这台设备的浏览器里，用于提前撤销。若清除浏览器数据则无法再撤销，但内容仍会在到期后自动销毁。

它是怎么保证安全的
1. 端到端加密：AES-256-GCM，密钥由密钥串经 PBKDF2-SHA256（15 万次迭代 + 随机盐）派生，加解密全过程在浏览器本地完成。
2. 密钥不上行：密钥放在 URL 的 # 片段里，浏览器请求时不会携带它，服务端在技术上无法解密。
3. 服务端只存密文：数据库中只有密文、随机盐和初始向量，没有明文、没有密钥、不记录 IP。
4. 到期即毁：过期后由存储层自动清除，读取时还会二次校验时间。开启阅后即焚则读完立即销毁。
5. 篡改可感知：GCM 认证标签会校验完整性，密文被改动或密钥错误都会直接解密失败。

注意：本工具只负责加密与传递，请勿用于分享违法违规内容。
